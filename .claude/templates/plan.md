## task 분리

vertical slice(task) 단위로 나눌 필요가 있는 경우에만 `task.md`를 만든다.

나누는 기준: 세부 기능이 3개 이상이거나, 구현이 여러 세션/커밋에 걸칠 것 같은 경우.

---

**작성 규칙 (designer 전용)**

- backlog.md `## 승인` 체크박스가 `[x]`가 아니면 이 파일을 쓰지 않는다.
- "영향 레이어/파일"은 추측이 아니라 실제로 관련 코드를 Read해서 확인한 내용으로 채운다.
- task.md를 만들기로 했으면, task 순서는 뒤 task가 앞 task에 의존하지 않도록(또는 의존
  관계를 task.md에 명시하도록) 나눈다 — implementer가 순서대로 처리하며 매 task 후 자동
  진행하기 때문이다.
